# Changelog

## 0.3.0

- Sign-in required for the whole app. Real server-side sign-in, with demo mode for presentations.
- Agency updates and decisions saved on the server, with role and agency checks, validation and an audit log.
- Hardening: lockouts per address and email, idle and absolute session limits, sessions end on password change, HTTPS settings, request timeouts, strict content security policy, no third-party requests.
- CSV export of all indicators, printable summary, demo-mode ribbon, reviewer shown on each update.
- Repository: build script, 15 server tests, CI, Docker, GitHub Pages demo, docs for the panel and pilot.

## 0.2.0

- Indicator names, IDs and values aligned to the UNSDCF evaluation, UN Botswana 2024 results report and UNDP evaluation. Agency update form with CSV upload and review queue.

## 0.1.0

- First working prototype with sample data.
